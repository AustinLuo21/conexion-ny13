# Conexión NY13 — 2-minute demonstration outline

**0:00–0:20 — Purpose.** “Conexión NY13 helps tenants in Washington Heights and Inwood keep an organized record of housing repair issues. It is a bilingual independent student tool, not an official reporting service.” Show Home and change English to Spanish and back.

**0:20–0:45 — New problem.** Select New Case, private rental, no heat, ongoing, no prior action. Create case. Show **Prepare your first repair request**, generate an editable initial message, explain that copying does not mark the message sent.

**0:45–1:05 — Record contact and successful outcome.** Back to case; Record an Action → Contacted Management. Save. Then What Happened? → Resolved. Show resolved timeline.

**1:05–1:35 — When the problem persists.** Load the clearly labeled fictional “Leak still unresolved” case, which already has earlier contact and a complaint. Show how the current physical condition differs from a closed complaint, and show the official follow-up and NMIC / Housing Court information.

**1:35–1:50 — Further options.** Open Documents → Assistance Summary; show full timeline and reference numbers, edit and copy. Open Print / Save as PDF. Switch Spanish.

**1:50–2:00 — Technical explanation.** “Built with React, TypeScript, deterministic rule-based recommendations, chronological event logs, bilingual content, and opt-in local browser saving. No personally identifying information is required to obtain guidance.”

Before recording, rehearse on the deployed URL with all three journeys and make sure the video describes only functionality that actually works.
